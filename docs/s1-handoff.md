# S1 操作手册与成员交接

主驾：成员 A；独立验收：成员 C。范围与状态以根 tasks.md 为准。

## 运行与日常操作

1. 使用 Node 24.18.0、npm 11.16.0，在仓库根目录执行 `npm ci`。
2. 默认配置可直接运行；需要更改端口或数据库路径时，从 `.env.example` 创建自己的 `.env`，不要覆盖已有配置或提交它。
3. 执行 `npm run db:init`。此命令只建库、迁移和补固定成员，可重复执行，不清空业务数据。
4. 终端一执行 `npm run dev:backend`；终端二执行 `npm run dev:frontend`。打开 `http://127.0.0.1:5173`。
5. 首次为空工作区，点“新建看板”，输入“课程作业”，提交后进入三个空列。
6. 点“新建任务”，输入标题，可补描述、负责人、日期、初始状态。保存成功后显示在对应状态列；仅填标题时为待办、未分配、未设置日期。
7. 点击卡片，查看完整描述、负责人、截止日期及创建/更新时间；这些值来自详情接口。
8. “刷新看板”或浏览器刷新会重新读取服务端。停止并重启后端时必须使用相同 DATABASE_PATH。

看板名称 1～50 个 Unicode 码点，任务标题 1～100，描述最多 2000。标题/名称去除首尾空白，描述保留换行；日期使用实际公历日期，业务时区 Asia/Shanghai。同名看板允许创建，以 ID 区分。

## 错误恢复

- 启动健康失败：页面阻断并显示“重试连接”；先检查后端和数据库，再点重试。
- 读取失败：显示错误与重试。刷新失败保留旧列表并标记可能已过期，不能把它当成空板。
- 成员读取失败：已分配任务显示“负责人信息不可用”，创建表单暂不允许保存；点击重试。
- 字段校验失败：保留输入并定位字段；修改后手动提交。
- 网络中断或 10 秒超时：不自动重放写请求。点击“刷新查证”，查看同名记录数量，取消表单查看真实列表；只有确认需要另一条记录时才再次创建。
- 有未保存内容时取消/切换：确认是否丢弃；取消确认会保留输入。提交中不能关闭或切换。

## 接口与代码交接

全部接口相对 `/api/v1`；成功为 `{data: ...}`，错误为 `{error: {code, message, fields?}}`。准确规则以 spec 第 4/8/9 节为准。

| 能力 | 接口 | 结果 |
| --- | --- | --- |
| 固定成员 | GET /members | 200，Member[] |
| 看板列表/创建 | GET/POST /boards | 200 Board[] / 201 Board |
| 看板详情 | GET /boards/:boardId | 200 Board |
| 任务列表/创建 | GET/POST /boards/:boardId/tasks | 200 Task[] / 201 Task |
| 任务详情 | GET /boards/:boardId/tasks/:taskId | 200 Task；跨板 404 |

- **B / S2：** 继续完善 BoardView 的导航与 useWorkspace 的加载、竞态、深链接；保持基础接口不变，新增切板场景测试。
- **C / S3：** 扩展 TaskForm 的编辑模式与 API 的 PUT/DELETE；目前只接收创建草稿，没有虚假的编辑按钮。日期纯规则在 shared，展示工具在 frontend/src/lib/dates.ts。
- **D / S4：** 继续加固双浏览器、异常、静态部署和备份恢复；HTTP 客户端已经统一 10 秒超时与错误映射，不自动重试写入。

- **数据库：** 沿用 0001，没有新增或改写迁移。写接口必须经过 writeRoute，不能绕过媒体类型/大小/JSON 守卫。
