## 审查与实际修正

此处为编码代理自查，**不代替 C 或另一名成员的独立评审**。

| 审查点 | 核对与结果 |
| --- | --- |
| 契约与范围 | 新增既定创建/读取 API，无新业务字段；编辑/删除仍未实现 |
| 持久化与归属 | 参数化 SQL、任务查询同时使用 boardId/taskId；创建任务事务内校验关联；失败无部分记录 |
| 输入边界 | 前后端共用纯规则；字段白名单、真实日期、码点长度及控制字符；数据库仍保留自己的约束 |
| HTTP 守卫 | 两个新增 POST 均经 writeRoute；测试覆盖 415/413/400/422、未知字段、Host 403 与脱敏错误 |
| 用户流程 | 保存锁、保留失败输入、读取失败不呈现为空、健康失败阻断；响应丢失后要求查证 |
| 内容安全 | Vue 纯文本插值，无 v-html；SQL 注入形态字符串按数据保存，脚本形态描述不执行 |
| 迁移兼容 | 沿用 0001，无改写或新增迁移，重复初始化不删除业务数据 |
| 交接 | 提供计划、手册、CHECK 映射及 B/C/D 扩展入口；未自动关闭切片 |

首次浏览器测试因测试夹具计算仓库根目录多上溯一级而失败（db:init 退出 1）；修正路径并增加初始化 stderr 诊断后通过。首次沙箱内 HTTP 测试出现 loopback EACCES，允许本机回环的执行环境下复跑通过。隔离安装还遇到沙箱虚拟临时路径无法用于外部进程，以及自动审批服务因账户用量限制未执行；改用工作区内隔离目录，在用户要求继续后重新通过正常审批完成安装。这些失败不归因为业务代码通过，也不省略历史记录。
