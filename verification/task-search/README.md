npm run check:api
$env:E2E_BROWSER_A='chrome'

可用 `E2E_EXECUTABLE_A/B` 指定已安装的便携浏览器。服务器仅装生产依赖时，构建产物已提供，可运行 `node tests/e2e/task-search.mjs --api-only`；该分支不加载 Playwright，仍自行创建临时真实数据库和随机端口。

## 失败与修正

- 新增 HTTP 测试辅助函数误标 async，Supertest 链被 Promise 吸收导致无法调用 expect；修正后完整后端通过。
- 原健康门禁将所有启用功能都当作前端不支持；更新支持范围，仍拒绝尚未实现的排序/分享配置。
- 在正常保存后独立处理筛选重读，避免读失败被表单当成写失败；单测和真实浏览器均验证仅发出一次 PUT。
- 刷新完整数据成功但筛选查询失败时补充刷新过期状态；错误和零匹配在组件层保持区分。
